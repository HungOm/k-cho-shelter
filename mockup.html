K'Cho Shelter — home screen

A design mockup, not the running app. Three artboards: the recommended phone layout, an alternate that leads with the work instead of the money, and the desktop shape.

Built on the app's own tokens — brand #0d7a6f, 17px base, 52px minimum tap target, 16px radii — so it extends the existing system rather than replacing it. The change from the current screen is threefold: no emoji anywhere (one stroke icon set on a 24px grid), one dominant number instead of several equal cards, and the book grid promoted from the footer to a centrepiece.

Figures shown are sample data. Open this file in any browser — it needs nothing installed and works offline.
